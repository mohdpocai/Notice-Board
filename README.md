# Notice Board – Leepang 2 Estate

Polisi, Garis Panduan & Kod Etika (BM / EN / TL) — opened by scanning one QR code.

- `index.html` – the page workers see on their phone
- `poster.html` – A4 QR poster to print
- `Senarai-Dokumen.csv` – backup copy of the document list

The live list comes from the Google Sheet **"Senarai Dokumen - Notice Board"** (Published to web as CSV).
To add / change / remove a document, edit the Sheet only. Changes show on phones in about 5 minutes.
